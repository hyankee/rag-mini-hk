# 香港绿色建筑与 PropTech 行业转行概览

## 1. 一句话

绿色建筑与 PropTech 的核心是“用数据和数字化工具，让建筑更节能、更健康、更好运维”，也是建筑背景转行 AI 应用开发最自然的桥梁。

## 2. 香港本地场景

香港建筑密度高、楼宇老化、能源成本高，绿色建筑、既有建筑节能、智慧楼宇、设施管理和 BIM/GIS 都有持续需求。行业关注绿色建筑认证、能源效率、室内环境、碳排放、减废和资产维护。

常见数据包括能耗账单、机电设备运行记录、楼宇管理系统数据、维护工单、租户投诉、BIM 模型和绿色认证文件。LLM 适合处理其中的文本和知识，而不是替代能耗仿真或工程计算。

## 3. 常见岗位（非实时招聘）

- 可持续发展 / 绿色建筑分析师：整理认证材料、能耗和碳排放数据。
- 楼宇数据分析：分析能耗、设备、工单和空间使用。
- PropTech 产品 / 项目：把物业和设施管理需求转成数字产品。
- BIM / GIS 协调：管理模型、数据标准和跨专业协作。
- 设施管理 / 机电工程：负责设备运行、维护和改造。
- LLM 应用开发工程师：做标准问答、招标文件抽取、工单摘要和 ESG 报告辅助。

## 4. 与 LLM 应用开发的结合点

1. **绿色建筑标准问答**：把认证手册、内部规范做成知识库，回答时带章节来源。
2. **招标与规范抽取**：从招标文件、技术规格和合同中抽取材料、性能、交付和验收条款。
3. **维护工单摘要**：把设备记录、投诉和维修历史整理成问题摘要和处理建议。
4. **ESG 报告辅助**：从多份数据表和政策文件中整理叙述草稿，数字必须回到源表核对。
5. **跨专业术语解释**：把机电、结构、建筑和物业术语转成不同团队能理解的语言。

## 5. 建筑背景的切入路径

这是你最有优势的方向。你不需要假装自己是纯算法工程师，而是可以成为“懂建筑、懂数据、会用 AI 工具”的复合型人才。优先目标是绿色建筑分析、楼宇数据、PropTech 产品支持、BIM 数据治理和设施管理数字化。

建议做一个组合项目：用 `RAG Doc` 里的绿色建筑材料做知识问答，再额外放几份合成招标文件做条款抽取。这个项目能同时展示行业理解和 LLM 应用能力。

## 6. 需要补的技能

- Python 数据处理：CSV/Excel、能耗数据、工单数据。
- SQL 与报表：能查数、对账、做基础可视化。
- 建筑数据标准：BIM、GIS、设备编码、空间编码的基本概念。
- RAG：标准、规范、招标文件的切片与引用。
- 结构化输出：材料、性能、单位、条款的字段抽取。
- 评测：数字是否正确、条款是否漏掉、来源是否可追溯。

## 7. 核验提示

绿色建筑认证、能源法规和建筑标准会更新，请查香港绿色建筑议会、机电工程署、环境保护署及相关官方文件。本文件只用于学习行业地图。
