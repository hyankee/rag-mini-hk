# 香港医疗与医疗科技行业转行概览

## 1. 一句话

香港医疗与医疗科技行业的核心是“在高隐私、高责任、强监管的环境里，用技术改善记录、流程、沟通和研究”。

## 2. 香港本地场景

香港的医疗体系包括公营医院、私营医院、诊所、康复与安老服务、医疗设备和健康科技公司。行业对病历、处方、检查结果和个人资料的保护要求很高；《个人资料（私隐）条例》（PDPO）等隐私规则是任何 AI 应用都必须先处理的前提，同时还要解决权限和人工复核问题。

常见技术工作包括医院信息系统、临床数据管理、医疗设备软件、远程医疗、健康应用和医学研究数据支持。LLM 可以辅助文档和知识工作，但不能替代医生诊断。

## 3. 常见岗位（非实时招聘）

- 健康信息学 / 临床数据分析：整理病历、编码、质量和报表。
- 医疗科技产品 / 实施：把临床需求转成产品流程。
- 法规与质量事务：准备注册、质量体系和风险管理文档。
- 医院 IT / 系统集成：对接 HMS、LIS、PACS 等系统。
- 医学写作 / 文献支持：整理研究资料和合规文档。
- LLM 应用开发工程师：做非诊断类问答、文档抽取、摘要和检索。

## 4. 与 LLM 应用开发的结合点

1. **患者常见问题**：回答就诊流程、预约、访客安排等非诊断问题，必须带官方来源。
2. **临床文档辅助**：帮助整理结构化病历草稿，由医护人员审核，不能自动签字。
3. **医学文献检索**：检索指南和论文片段，标注出处，辅助综述。
4. **编码与账单辅助**：从文档中提示可能的编码，最终由专业人员确认。
5. **多语言健康沟通**：粤语、普通话、英语之间的健康教育材料改写，避免改变医学含义。

## 5. 建筑背景的切入路径

建筑行业的安全管理、合规检查、项目文档和多方审批，与医疗行业的质量、风险和流程管理有相似之处。你可以先从“医疗运营 / 合规 / 项目支持”类岗位切入，再补数据与 AI 技能。

需要明确：临床岗位通常需要专业资格；没有医学背景时，不要直接应聘需要诊断或处方责任的职位。更适合的方向是健康信息学、医疗科技实施、质量法规、医院 IT 和文档智能化。

## 6. 需要补的技能

- Python 与 SQL：处理结构化数据和报表。
- 医学术语与流程：至少能读懂常见科室、病历结构和编码概念。
- 隐私与合规：PDPO、个人资料最小化、访问控制、日志脱敏、人工复核。
- RAG：指南、SOP、患者手册的检索与引用。
- 评测：事实准确性、遗漏、误导性表述和安全性。
- 人机协作：明确哪些输出只能做草稿，哪些必须由专业人员确认。

## 7. 核验提示

真实法规、临床指南和医院流程请查医院管理局、卫生署、个人资料私隐专员公署及相关专业机构。本文件不构成医疗、法律或合规建议。
