# 香港旅游与酒店行业转行概览

## 1. 一句话

香港旅游与酒店行业的核心是“在多种语言、多种渠道和高峰客流下，提供稳定、个性化、可复盘的客户体验”。

## 2. 香港本地场景

香港的旅游相关业务包括酒店、景点、旅行社、会展与商务旅游、餐饮零售和交通接驳。行业同时服务本地客、内地客和国际客，语言、支付方式、预订渠道和期望差异都很大。

常见工作包括预订管理、客户咨询、投诉处理、房态与收益分析、活动执行、渠道运营和社交媒体内容。高峰期信息量大、变化快，适合用检索和摘要工具辅助一线员工。

## 3. 常见岗位（非实时招聘）

- 收益 / 数据分析：房价、入住率、渠道和客群分析。
- 客户体验 / 运营：处理咨询、投诉、特殊需求和现场协调。
- 数字营销 / 内容运营：管理社交媒体、OTA 页面和多语言内容。
- 会展与活动执行：协调场地、供应商、日程和嘉宾。
- 旅游科技产品 / 系统人员：对接预订、CRM、支付和客服系统。
- LLM 应用开发工程师：做多语言客服、评论分析、行程草稿和知识库问答。

## 4. 与 LLM 应用开发的结合点

1. **多语言礼宾问答**：回答交通、设施、入住、餐饮和景点问题，答案要带酒店政策来源。
2. **评论与投诉摘要**：把大量评价归纳成主题、情绪和可行动建议。
3. **行程草稿**：根据客人偏好生成初稿，但时间、价格和可用性要由业务系统确认。
4. **客服辅助**：检索退款、改期、行李、儿童政策等条款，减少一线人员查资料时间。
5. **内容本地化**：把景点和活动介绍改写成粤语、普通话、英语版本，保留事实一致。

## 5. 建筑背景的切入路径

建筑行业的项目协调、供应商管理、现场问题处理和进度沟通，可以迁移到会展、酒店运营和旅游项目执行。你擅长把多方需求落到时间表和责任人，这在高峰运营中很有价值。

转技术岗位时，建议从“运营 + 数据 + AI 工具”的混合岗位切入，例如客户体验分析、数字运营或旅游科技产品支持，而不是一开始就做纯算法。

## 6. 需要补的技能

- Python 与表格处理：清洗预订、评论和问卷数据。
- SQL / CRM：理解客户、订单、渠道和复购。
- Prompt 与 RAG：多语言问答、政策检索、引用来源。
- 内容评测：事实一致性、语气、长度、文化适配。
- 隐私：客户姓名、联系方式、订单信息必须脱敏。
