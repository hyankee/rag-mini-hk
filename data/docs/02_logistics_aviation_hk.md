# 香港物流与航空货运行业转行概览

## 1. 一句话

香港物流与航空货运的核心是“让货物按时、合规、可追踪地流动”，每天处理大量单证、异常和时间压力。

## 2. 香港本地场景

香港国际机场是全球重要的航空货运枢纽，周边聚集货运代理、航空公司、地面服务商、报关行、第三方物流和冷链服务。行业里既有高度自动化的仓库，也有大量依赖邮件、Excel、PDF 和电话的协调工作。

常见业务包括空运提单、商业发票、装箱单、报关文件、货运跟踪、异常处理、冷链温控和客户查询。很多信息分散在不同系统与格式里，适合用结构化抽取和检索来减少人工整理。

## 3. 常见岗位（非实时招聘）

- 运营分析师：分析航班、货量、时效、仓库和异常数据。
- 供应链分析师：做库存、运输、成本和履约分析。
- 系统分析师：对接货运系统、EDI、API 和内部报表。
- 自动化 / 数字化项目人员：推动单证、扫描、OCR 和流程自动化。
- 客户服务与异常处理：跟进延误、破损、清关和改单。
- LLM 应用开发工程师：做单证抽取、SOP 问答、异常摘要和多语言客服辅助。

## 4. 与 LLM 应用开发的结合点

1. **单证抽取**：从空运提单、发票、装箱单中抽取航班号、件数、重量、收货人、品名等字段。
2. **异常摘要**：把邮件、工单和跟踪记录整理成“发生了什么、影响什么、下一步做什么”。
3. **SOP 助手**：把操作手册和客户要求做成可检索知识库，回答时带章节来源。
4. **多语言客服**：辅助处理英语、粤语、普通话的查询和回复。
5. **报关资料检查**：提示缺失字段或不一致项，但最终由有资质人员确认。

## 5. 建筑背景的切入路径

建筑行业的现场协调、分包商管理、材料进场、进度追和文档留痕，与物流行业的“多角色、多单证、强时效”很相似。你可以把过去的经验转成“流程理解 + 异常处理 + 跨团队沟通”的优势。

建议先做一个小项目：把 10 份合成提单/发票做成字段抽取，比较规则、正则和 LLM 抽取的效果。这个项目比空泛的“聊天机器人”更接近物流岗位的真实需求。

## 6. 需要补的技能

- Python 文件处理：PDF/Excel/CSV 读取、批量处理。
- 正则表达式与字段清洗：重量、日期、港口代码、箱号。
- JSON 与结构化输出：字段缺失、单位不一致、低置信度处理。
- API 与 EDI 基础：理解系统之间怎么传数据。
- RAG：SOP、客户规则、异常处理手册的检索与引用。
- 数据隐私与商业保密：货主、价格、路线信息不能随意外发。
