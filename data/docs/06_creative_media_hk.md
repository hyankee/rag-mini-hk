# 香港创意媒体与广告行业转行概览

## 1. 一句话

香港创意媒体与广告行业的核心是“用内容影响人”，LLM 在这里更多是创作助手、 localization 工具和内容分析工具，而不是替代创作者。

## 2. 香港本地场景

香港的创意相关业务包括广告、电影电视、动画、出版、社交媒体、游戏、品牌咨询和活动制作。市场同时面向本地、内地和国际客户，常见需求是双语/三语内容、快速改稿、跨平台适配和短周期制作。

行业里大量工作是提案、脚本、分镜、字幕、社媒文案、素材管理和客户沟通。LLM 可以加速初稿、改写、翻译和归纳，但版权、事实准确性和品牌语气仍要人来把关。

## 3. 常见岗位（非实时招聘）

- 内容策略 / 文案：品牌语气、 campaign 概念和多渠道内容。
- 制片 / 项目管理：预算、排期、供应商和交付。
- 数字营销 / 社媒运营：内容日历、投放素材和数据复盘。
- 创意技术 / 制作支持：把工具接入制作流程。
- 本地化 / 字幕：翻译、字幕、配音稿和术语统一。
- LLM 应用开发工程师：做创意助手、内容检索、字幕和素材摘要工具。

## 4. 与 LLM 应用开发的结合点

1. **创意初稿**：根据 brief 生成多个方向，再由人筛选和改写。
2. **脚本与分镜辅助**：把大纲转成场景草稿，保持角色和品牌一致性。
3. **字幕与本地化**：生成初版字幕和翻译，保留术语表和时间轴。
4. **内容再利用**：把长视频、访谈和文章拆成社媒短文、摘要和标题。
5. **素材与品牌知识库**：检索品牌指南、历史 campaign 和客户偏好，回答时带来源。

## 5. 建筑背景的切入路径

建筑行业的项目制工作、效果图/可视化、供应商协调和客户沟通，可以迁移到创意制作与活动管理。你如果有建筑可视化、渲染或空间叙事经验，可以向“创意技术 / 制作支持 / 空间内容”方向靠拢。

转技术岗位时，作品集比证书更重要。建议做 2–3 个可展示的小项目：品牌知识库问答、长内容拆条、字幕本地化助手。

## 6. 需要补的技能

- 写作与叙事：能判断什么是好内容，而不只是会调用模型。
- Python 与 API：批量处理文本、图片、字幕和文件。
- Prompt 与评测：风格一致性、事实准确性、长度和文化适配。
- 版权基础：训练数据、素材授权、生成内容的商用风险。
- RAG：品牌指南、客户资料、历史项目的检索与引用。
