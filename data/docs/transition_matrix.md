# 建筑行业转行香港热门行业的路径矩阵

## 1. 先盘点可迁移能力

建筑行业常见能力中，最适合迁移到 AI 应用岗位的不是“画图速度”，而是：

- 读复杂文档：合同、规范、招标文件、图纸说明、进度报告。
- 多角色协调：业主、顾问、承建商、分包商、供应商。
- 约束管理：成本、工期、质量、安全、审批。
- 留痕与复核：版本、变更、验收、责任边界。
- 现场问题处理：信息不完整时推进事情。

这些能力在“文档密集型 RAG”和“业务流程数字化”里很值钱。

## 2. 路径矩阵

| 现在的角色 | 可迁移优势 | 目标行业 | 入口岗位 | 主要缺口 |
|---|---|---|---|---|
| 项目协调 / 项目助理 | 多方协调、进度、文档 | 物流、旅游、PropTech | 运营分析、项目支持、数字化助理 | Python、SQL、API |
| 造价 / 工料测量 | 数字敏感、合同、成本 | 金融科技、PropTech | 业务分析、成本数据、合规文档 | Python、数据可视化、隐私 |
| BIM / 建模 | 数据标准、模型、空间信息 | 绿色建筑、PropTech | BIM 数据、楼宇数据、产品支持 | Python、数据库、RAG |
| 现场工程师 | 流程、安全、异常处理 | 物流、医疗运营、设施管理 | 运营分析、系统实施、流程数字化 | 编程、数据、英文技术文档 |
| 合同 / 采购 | 条款、供应商、风险 | 金融科技、物流、医疗合规 | 合规科技、采购分析、文档智能化 | Python、SQL、评测 |
| 可持续 / 绿色建筑 | 认证、能耗、法规 | 绿色建筑、ESG、PropTech | 可持续分析、ESG 数据、标准问答 | 数据分析、LLM 应用 |

## 3. 推荐的三项目组合

### 项目 A：结构化抽取

输入工程文本，输出经过 Pydantic 校验的材料、数量、单位、证据字段。展示你理解“模型输出不可信，需要校验”。

### 项目 B：行业 RAG

用 `RAG Doc` 的 6 个行业文档做知识库，支持问题检索、带来源回答、无证据拒答。展示你理解完整 RAG 链路。

### 项目 C：评测报告

用 `qa/sample_questions.md` 的 10–12 道题，记录每题：检索到了什么、答案是否正确、引用是否正确、失败原因。展示你能评估系统，而不是只看 demo。

## 4. 六周学习节奏中的位置

- 第 1 周：Python 工程化、HTTP/JSON、DeepSeek API、结构化输出。
- 第 2 周：RAG MVP：语料、切片、检索、引用、拒答、评测。
- 第 3 周：把 RAG 接入一个真实业务流程，补 SQL 和简单后端。
- 第 4 周：评测与优化：检索命中、回答质量、成本、延迟。
- 第 5 周：做一个行业作品集，写 README 和限制说明。
- 第 6 周：投递、面试讲述、根据 JD 补缺口。

## 5. 最现实的切入点

如果目标是尽快转行，优先级建议：

1. **绿色建筑 / PropTech**：你的建筑知识直接加分，行业门槛最低。
2. **金融科技合规文档 / 物流单证**：文档密集，RAG 和结构化抽取价值明确。
3. **医疗非临床文档**：需求真实，但隐私和合规要求更高。
4. **旅游 / 创意媒体**：岗位更偏运营和内容，技术深度因公司而异。

## 6. 核验提示

岗位名称、薪资、签证要求和招聘状态会变化。请用 JobsDB、LinkedIn、HKSTP、Cyberport 和公司官网核对实时信息。
